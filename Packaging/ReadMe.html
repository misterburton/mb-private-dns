Your network configurations are preserved

Private DNS configures eligible network services that use automatic DNS. Services with custom DNS, including show networks, direct device connections, disabled services and saved network locations, are preserved. They do not block installation.

After installation, open Details from the menu bar to see exclusions with their service IDs, locations and DNS addresses. Excluded services are outside Private DNS protection. You do not need to delete custom network configurations.

An existing encrypted-DNS profile or another service using 127.0.0.1:53 can still prevent installation. Safety checks run before this installer stops Private DNS or changes its files or DNS. If installation stops, choose Window → Installer Log and show all logs to read the specific explanation. Do not remove unrelated network settings.

The background entries are associated with Private DNS. macOS may retain an older label until its background-item list refreshes.
